## 🚀 如何上傳到 GitHub 並開啟網頁使用

本資料夾已為您打包好**完整的靜態網頁檔案（僅 3 個核心檔案）**，可以直接透過 GitHub 網頁上傳，不會再遇到「超過 100 個檔案」的限制！

### 步驟 1：建立 GitHub 儲存庫
1. 前往 [GitHub.com](https://github.com/) 並登入。
2. 點擊右上角 **「+」** > **「New repository」**。
3. 儲存庫名稱輸入 `garam`（可自訂），設為 **Public**，點擊 **「Create repository」**。

### 步驟 2：直接拖曳上傳檔案（網頁介面上傳）
1. 在新建立的儲存庫頁面中，點擊 **「uploading an existing file」** 連結。
2. 將 `garam` 資料夾內的所有檔案與資料夾拖曳進瀏覽器中：
   - 📄 `index.html`
   - 📁 `assets` 資料夾（內含 js 與 css）
   - 📄 `README.md`（可選）
3. 頁面下方點擊綠色的 **「Commit changes」** 按鈕儲存。

### 步驟 3：開啟 GitHub Pages 免費網頁服務
1. 進入該儲存庫上方的 **Settings**（設定）分頁。
2. 點擊左側選單的 **Pages**。
3. 在 **Build and deployment** 下方：
   - **Source**：選擇 `Deploy from a branch`
   - **Branch**：選擇 `main`（或 `master`），資料夾保持 `/ (root)`
4. 點擊 **Save**（儲存）。
5. 等候約 30 秒至 1 分鐘重新整理頁面，頂部就會出現您的專屬網頁網址：
   👉 **`https://您的帳號.github.io/garam/`**

點擊該網址即可直接在任何裝置上使用 GARAM 算術拼圖出題與列印功能！
